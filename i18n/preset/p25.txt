Hệ thống làm đẹp giao diện là gì

Hệ thống làm đẹp giao diện dùng regex của SillyTavern để định vị phần nội dung nhất định trong kết quả của AI, thay nó bằng khối mã giao diện, rồi trong khối mã đó dùng getChatMessages để lấy nguyên văn tin nhắn, tự phân tích và render thành giao diện HTML đẹp mắt.

Kiến trúc cốt lõi

1. Regex SillyTavern: định vị vùng thẻ nhất định trong kết quả của AI, thay nó bằng khối mã giao diện
2. Mã giao diện: nạp trong khối mã, dùng getChatMessages để lấy nội dung gốc của tin nhắn, tự phân tích dữ liệu và render giao diện

Nguyên tắc quan trọng

Regex chỉ lo định vị, không lo truyền dữ liệu:
- Nhiệm vụ duy nhất của regex là tìm vùng thẻ và thay bằng khối mã của giao diện
- Cấm dùng $1 trong regex để bắt và truyền dữ liệu
- Việc lấy dữ liệu được làm trong mã giao diện thông qua getChatMessages

Các thẻ bị cấm dùng (sẽ gây lỗi hệ thống):

Tệp hai (chế độ A): mã HTML giao diện

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>Làm đẹp nội dung chính</title>
    <style>
        * {
            margin: 0;
            padding: 0;
            box-sizing: border-box;
        }

        body {
            font-family: "Microsoft YaHei", sans-serif;
            background: transparent;
            padding: 8px;
        }

        .story-container {
            max-width: 650px;
            margin: 0 auto;
            padding: 24px 32px;
            line-height: 1.9;
            font-size: 15px;
            color: #d4d4d4;
        }

        /* Thiết kế kiểu dáng tự do theo nhu cầu người dùng */
        /* Ví dụ: hiệu ứng giấy viết thư, hiệu ứng sổ nhật ký, bong bóng thoại... */

        .loading {
            text-align: center;
            padding: 20px;
            color: #999;
        }
    </style>
</head>
<body>
    <div class="story-container" id="content">
        <div class="loading">Đang tải...</div>
    </div>

    <script>
        /* ========== Lấy nội dung tin nhắn ========== */
        function getMessageData() {
            var chatMessages = getChatMessages(getCurrentMessageId());
            if (!chatMessages || chatMessages.length === 0) {
                console.error("Không lấy được nội dung tin nhắn");
                return null;
            }
            return chatMessages[0].message;
        }

        /* ========== Trích phần nội dung chính ========== */
        function extractContent(messageText) {
            var match = messageText.match(/<story>([\s\S]*?)<\/story>/);
            if (match && match[1]) {
                return match[1].trim();
            }
            return messageText;
        }

        /* ========== Render giao diện ========== */
        function renderPage(text) {
            /* Chuyển xuống dòng thành đoạn */
            var paragraphs = text.split(/\n\s*\n/);
            var html = '';
            paragraphs.forEach(function(p) {
                var trimmed = p.trim();
                if (trimmed) {
                    /* Xử lý dòng thoại và dòng tường thuật */
                    if (trimmed.startsWith('"') || trimmed.startsWith('"') || trimmed.startsWith('「')) {
                        html += '<p class="dialogue">' + trimmed + '</p>';
                    } else {
                        html += '<p class="narrative">' + trimmed + '</p>';
                    }
                }
            });
            document.getElementById('content').innerHTML = html;
        }

        /* ========== Hàm chính ========== */
        function init() {
            try {
                var messageText = getMessageData();
                if (!messageText) {
                    document.getElementById('content').innerHTML =
                        '<div class="loading">❌ Không lấy được nội dung tin nhắn</div>';
                    return;
                }
                var text = extractContent(messageText);
                renderPage(text);
            } catch (error) {
                console.error("Lỗi:", error);
                document.getElementById('content').innerHTML =
                    '<div class="loading">❌ Tải thất bại: ' + error.message + '</div>';
            }
        }

        $(function() { init(); });
    </script>
</body>
</html>
```

Cấu trúc cốt lõi giống chế độ A, khác ở chỗ phần logic phân tích phức tạp hơn:

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>Tiêu đề trang</title>
    <style>
        * {
            margin: 0;
            padding: 0;
            box-sizing: border-box;
        }

        body {
            font-family: "Microsoft YaHei", sans-serif;
            background: transparent;
            padding: 8px;
        }

        .container {

            margin: 0 auto;
            border-radius: 12px;
            padding: 16px;
        }

        .loading {
            text-align: center;
            padding: 20px;
            color: #999;
        }

        /* Thiết kế kiểu dáng tự do theo nhu cầu người dùng */
    </style>
</head>
<body>
    <div class="container" id="content">
        <div class="loading">Đang tải...</div>
    </div>

    <script>
        /* ========== Lấy nội dung tin nhắn ========== */
        function getMessageData() {
            var chatMessages = getChatMessages(getCurrentMessageId());
            if (!chatMessages || chatMessages.length === 0) {
                console.error("Không lấy được nội dung tin nhắn");
                return null;
            }
            return chatMessages[0].message;
        }

        /* ========== Phân tích dữ liệu ========== */
        function parseData(messageText) {
            var result = {};

            /* Trích nội dung thẻ từ tin nhắn đầy đủ */
            var tagMatch = messageText.match(/<ten_the>([\s\S]*?)<\/ten_the>/);
            if (!tagMatch || !tagMatch[1]) {
                console.error("Không tìm thấy nội dung thẻ");
                return result;
            }
            var content = tagMatch[1];

            /* Phân tích theo định dạng dữ liệu đã chọn */
            /* Cách phân tích định dạng [trường|giá trị] */
            var match = content.match(/\[ten_truong\|([^\]]+)\]/);
            if (match && match[1]) {
                var parts = match[1].split('|');
                result.field1 = parts[0] || '';
                result.field2 = parts[1] || '';
            }

            /* Cách phân tích định dạng khoá-giá trị */
            var lines = content.trim().split('\n');
            lines.forEach(function(line) {
                var kv = line.split(':');
                if (kv.length >= 2) {
                    var key = kv[0].trim();
                    var value = kv.slice(1).join(':').trim();
                    result[key] = value;
                }
            });

            return result;
        }

        /* ========== Render giao diện ========== */
        function renderPage(data) {
            var html = '';
            /* Dựng HTML theo nhu cầu người dùng */
            document.getElementById('content').innerHTML = html;
        }

        /* ========== Hàm tương tác ========== */
        function handleClick(keyword, param) {
            if (typeof triggerSlash === 'function') {
                triggerSlash('/send ' + keyword + '：' + param + '|/trigger');
            }
        }

        /* ========== Hàm chính ========== */
        function init() {
            try {
                var messageText = getMessageData();
                if (!messageText) {
                    document.getElementById('content').innerHTML =
                        '<div class="loading">❌ Không lấy được nội dung tin nhắn</div>';
                    return;
                }
                var data = parseData(messageText);
                renderPage(data);
            } catch (error) {
                console.error("Lỗi:", error);
                document.getElementById('content').innerHTML =
                    '<div class="loading">❌ Tải thất bại: ' + error.message + '</div>';
            }
        }

        $(function() { init(); });
    </script>
</body>
</html>
```

   Giải thích:
   - strategy.type là "selective" (đèn xanh lá / kích hoạt theo từ khoá), keys điền các từ kích hoạt do người dùng định nghĩa
   - position đặt là D0 system để bảo đảm phần định nghĩa định dạng nhìn thấy được khi AI xuất kết quả
   - recursion chặn hai chiều để tránh các mục đệ quy làm nhiễu nhau
   - Nếu người dùng muốn giao diện này có hiệu lực mỗi lần AI xuất kết quả (thay vì kích hoạt theo từ khoá), đổi thành strategy: { type: "constant" }
6. Dùng công cụ Write để ghi mã HTML vào regex của nhân vật:
   - Đường dẫn: /Characters/<tên nhân vật>/Regex/[Giao dien] <ten trang>
   - Nội dung: mã HTML đầy đủ, bắt buộc bọc trong khối mã ``` (tức mở bằng ``` và đóng bằng ```, ở giữa là HTML đầy đủ)
7. Sau khi tạo regex, nhắc người dùng xác nhận các thiết lập sau trong bảng regex của SillyTavern:
   - Biểu thức regex tìm kiếm: <ten_the>[\s\S]*?</ten_the> (tương ứng thẻ AI xuất ra)
   - Tích chọn: Kết quả AI ✅, Chạy khi chỉnh sửa ✅, Chỉ hiển thị định dạng ✅

Quy chuẩn chung khi viết mã

1. Lấy dữ liệu: bắt buộc dùng getChatMessages(getCurrentMessageId()) để lấy tin nhắn
2. Định dạng chú thích: chỉ dùng /* chú thích */, cấm dùng // chú thích (sẽ gây lỗi render)
3. Thời điểm nạp: dùng $(function() { init(); }); chứ không dùng DOMContentLoaded
4. Thích ứng chiều cao: cấm dùng đơn vị vh, dùng width và aspect-ratio để chiều cao tự co giãn
5. Màu nền: nếu kiểu dáng hợp với hình thẻ hơn thì đừng đặt màu nền, trừ khi người dùng yêu cầu rõ ràng
6. Thích ứng trang: toàn trang phải vừa với chiều rộng container, không sinh thanh cuộn ngang
7. Tránh dùng min-height, overflow: auto và các thuộc tính ép cao container cha
8. Phần nội dung chính không được dùng position: absolute hay các kiểu tách khỏi luồng tài liệu
9. Xử lý giá trị rỗng: mọi trường được render đều phải có phương án dự phòng || '' hoặc || 'giá trị mặc định'
10. Xử lý lỗi: bọc phần logic cốt lõi trong try-catch

Giải thích chức năng bấm để gửi (dùng chung cho cả hai chế độ):
   Quy trình làm việc (4 bước):
   1. Bấm vào phần tử → tự gửi một câu trả lời với tư cách người dùng
   2. AI nhận được câu trả lời của người dùng → nhận diện từ khoá
   3. Từ khoá kích hoạt mục world book → AI đọc phần định nghĩa định dạng
   4. AI xuất nội dung tương ứng → regex thay thành giao diện đã làm đẹp

   Cách thực hiện:
   function handleClick(keyword, param) {
       if (typeof triggerSlash === 'function') {
           triggerSlash('/send ' + keyword + '：' + param + '|/trigger');
       }
   }

   Hiểu cốt lõi:
   - Bấm = tự thay người dùng gửi một câu trả lời + kích hoạt AI tạo nội dung
   - Không phải chuyển trang, mà là luồng đối thoại của LLM
